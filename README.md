# Мини-синхронизатор заявок

Живой JSON API: https://orders-sync-emin-20261013.arcane-pixie-1113.chatgpt.site/api/clients

JavaScript ES module на Cloudflare Workers (публикация через ChatGPT Sites), без зависимостей и базы данных. GET `/` и `/api/clients` получают свежий JSON из `https://test.ooobs.ru/api/orders` и возвращают только `clients` и `stats`.

## Правила

- Удаляем символы форматирования телефона. К 10 цифрам добавляем `7`, у 11 цифр заменяем начальную `8` на `7`; принимаем только `7` и ещё 10 цифр. Остальные телефоны отбрасываем.
- Группируем по нормализованному телефону. Побеждает максимальный `amount`, при равенстве — позднейший `created_at`, сравниваемый как timestamp. Поля имени и email берём целиком у победителя, включая пустой email.
- При полном равенстве сохраняем первую запись. Клиентов сортируем по телефону для стабильного ответа.
- `duplicates_merged` = количество валидных заявок минус число уникальных телефонов. Всегда выполняется `received = unique + duplicates_merged + invalid_dropped`.
- На каждом запросе строим новый Map, без накопления состояния. При неизменном источнике результат идентичен.
- Таймаут источника — 15 секунд. Ошибка источника даёт HTTP 502; это не успешный результат синхронизации. Успешный ответ HTTP 200 точно соответствует заданной схеме.

## Локальный запуск

Нужен Node.js 22+; установка пакетов не требуется.

```sh
npm test
npm start
curl http://localhost:3000/api/clients
```

Переменные окружения: `PORT` (по умолчанию 3000), `ORDERS_URL` (по умолчанию адрес задания). Для Vercel/Render/Railway можно использовать Node HTTP адаптер `server.mjs` на хостинге с Node-процессом; для Workers точка входа — `worker/index.js`.

## Секреты и публикация

Источник публичный, поэтому приложению секреты не нужны. Если потребуется токен источника, его следует хранить в secret-переменных хостинга, не в коде; `.env` исключён из Git. Учётные данные публикации используются только в окружении/памяти сессии и не входят в репозиторий или сборку.

`npm run build` создаёт `dist/server/index.js` и `.openai/hosting.json`, пригодные для публикации через Sites. Тесты проверяют форматы телефонов, правила выбора дублей, статистику, идемпотентность и HTTP-ответы.
